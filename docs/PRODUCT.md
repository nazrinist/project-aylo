# Project Aylo — Product Definition

## Promise
**Tell Aylo what you need. Aylo gets it done.**

## V1 wedge
Beauty services in Baku: hair, makeup, nails, lashes and brows.

## Core job-to-be-done
Turn an unstructured request into a shortlist of providers that match service, location, budget and time, then convert the selected offer into a confirmed booking.

## Non-goals for V1
- Universal web browsing for every category
- Autonomous payment without confirmation
- Full Instagram/WhatsApp automation
- Medical/cosmetic medical procedures
- Complex multi-agent architecture

## North-star metric
Completed intents per week.

## First funnel
Request → structured intent → search → ranked offers → user confirmation → booking.

## Closed-beta goal
Invite 50 real testers to use Aylo for one beauty appointment they could book
in the current week. Measure useful options, booking requests, no-match cases,
technical blockers, and ease of use without collecting tester identity.

## Public-beta goal
Open the same narrow Baku beauty journey without accounts or invite codes while
protecting availability and AI cost with pseudonymous session limits. Optimize
for completed intents per week, useful-option rate, booking-request rate, and
reliability—not raw traffic or chat volume.
